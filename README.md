# Pac-Man (3 Seviye)

Tek dosyalık (`index.html`) HTML5 canvas Pac-Man oyunu. Derleme gerektirmez; dosyayı tarayıcıda açmanız yeterli.

- 3 seviye: her seviyede farklı labirent, renk, hayalet sayısı/hızı ve daha kısa korku süresi
- Hayalet davranışları: Blinky, Pinky, Inky, Clyde (kovalama/dağılma modları)
- Güç topları, hayalet yeme kombo puanı, tünel, 3 can, rekor kaydı (localStorage)
- Kontroller: Ok tuşları / WASD · P duraklat · M ses · mobilde kaydırma
